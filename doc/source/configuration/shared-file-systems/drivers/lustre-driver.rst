=============
Lustre driver
=============

The Lustre driver enables Manila to export shared filesystems backed
by a pre-provisioned `Lustre <https://www.lustre.org/>`_ parallel
filesystem. Shares are sub-directories with project-quota-based
capacity enforcement and nodemap-based IP access control.

For deployment guidance, prerequisites and usage examples, see
:doc:`../../../admin/lustre_driver`.

Configuration Reference
-----------------------

All configuration options for this driver are documented in the
:doc:`Configuration Reference </configuration/shared-file-systems/config-reference>`.
